# Chenxuan Lu Portfolio

Portfolio of Chenxuan Lu, a multilingual content and brand marketer based in Barcelona: photography, short film and illustration.

Live site: https://luchenxuan.github.io/

## SEO files

- `robots.txt`: lets all crawlers in and points them to the sitemap
- `sitemap.xml`: lists the home page and its portfolio images; update `<lastmod>` and add new pages here when the site changes
- `llms.txt`: short plain-text summary of the site for AI search tools
- `404.html`: page shown for broken or mistyped links (not indexed)
- Structured data (schema.org `Person`, `WebSite`, `ProfilePage`) lives in the `<head>` of `index.html`
